## 1. 产品概述

### 1.1 产品定位

MoreAni（又看一集）v2.0 是一款**面向小圈子朋友的内部内容分享工具**，用于统一管理、评分和分享番剧、电影、游戏、软件、网站、书籍等内容。

**核心定位关键词**：
- **内部工具**：非公开产品，面向 5-10 人的朋友小圈子
- **分享驱动**：通过分享链接邀请朋友浏览内容
- **轻量化**：功能精简、操作简单，不需要复杂学习成本
- **全类型覆盖**：从番剧扩展到电影、游戏、软件、网站、书籍

### 1.2 目标用户

| 特征 | 描述 |
|------|------|
| 人数 | 5-10 人 |
| 关系 | 朋友，有共同追番/追剧/游戏兴趣 |
| 使用场景 | 手机/电脑浏览器访问 |
| 使用频率 | 每周几次 |
| 技术水平 | 普通用户，不需要复杂操作 |

### 1.3 产品目标

| 目标 | 指标 | 优先级 |
|------|------|:------:|
| 内容管理统一化 | 支持 6 种内容类型，统一 CRUD | P0 |
| 观看状态可追踪 | 每个用户可标记想看/在看/看完 | P0 |
| 评分体系精细化 | 百分制双维度评分 | P0 |
| 分享链接便捷化 | 一键生成分享链接 | P1 |
| 用户体验友好化 | 弹窗化交互、响应式设计 | P1 |
| 安全防护基础化 | 限流、防暴力破解、访问控制 | P1 |

### 1.4 技术栈

| 层 | 选择 |
|----|------|
| 前端 | React 18 + TypeScript + Tailwind CSS + shadcn/ui |
| 状态管理 | Zustand |
| 路由 | React Router v6 |
| 构建 | Vite |
| 后端 | Python FastAPI + SQLAlchemy 2.0 |
| 数据库 | SQLite |
| 部署 | Docker + Cloudflare Tunnel |
| 域名 | moreani.lovelysia.top |

## 2. 用户角色与权限

### 2.1 角色定义

系统包含三种用户角色：

| 角色 | 标识 | 说明 |
|------|------|------|
| **管理员 (admin)** | `role = 'admin'` | 系统管理者，拥有全部权限 + 用户管理 |
| **普通用户 (user)** | `role = 'user'` | 已注册用户，拥有全部读写权限 |
| **游客 (guest)** | 无账号 | 通过分享链接访问，仅拥有只读权限 |

### 2.2 权限矩阵

| 操作 | 未登录 | 游客 (guest) | 普通用户 (user) | 管理员 (admin) |
|------|:------:|:------------:|:---------------:|:--------------:|
| 查看登录页 | ✅ | ✅ | ✅ | ✅ |
| 浏览全站内容 | ❌ | ✅（只读） | ✅ | ✅ |
| 搜索内容 | ❌ | ✅（只读） | ✅ | ✅ |
| 查看评分/评论 | ❌ | ✅ | ✅ | ✅ |
| 创建/编辑/删除内容 | ❌ | ❌ | ✅ | ✅ |
| 评分（score + recommend） | ❌ | ❌ | ✅ | ✅ |
| 写评论 | ❌ | ❌ | ✅ | ✅ |
| 设置观看状态 | ❌ | ❌ | ✅ | ✅ |
| 创建分享链接 | ❌ | ❌ | ✅ | ✅ |
| 管理标签 | ❌ | ❌ | ✅（自定义标签） | ✅ |
| 用户管理（查看/禁用） | ❌ | ❌ | ❌ | ✅ |

### 2.3 未登录行为

- 未登录用户访问任何页面，自动弹出登录/注册弹窗
- 不展示任何内容数据
- 分享链接例外：通过分享链接可直接进入游客模式

### 2.4 游客（分享链接）行为

- 通过 `/guest/:token` 进入游客模式
- 可浏览全站内容（所有 `is_public = 1` 的内容）
- 可搜索内容
- 可查看所有评分和评论
- **不可**看到评分/评论的用户名和头像（游客脱敏）
- **不可**执行任何写操作（评分、评论、状态标记等）
- 游客视图中的「最近动态」匿名显示（只有内容名称，无用户信息）

## 3. 功能模块详细规格

### 3.1 内容管理模块

#### 3.1.1 数据模型

采用统一 `content_items` 模型，公共字段 + JSON `metadata` 存储各类型特有字段。

**内容类型枚举**：

| 类型值 | 中文名 | 说明 |
|--------|--------|------|
| `anime` | 番剧 | TV 动画、OVA、剧场版等 |
| `movie` | 电影 | 真人电影、纪录片等 |
| `game` | 游戏 | PC、主机、手游等 |
| `software` | 软件 | 工具、应用等 |
| `website` | 网站 | 在线服务、工具站等 |
| `book` | 书籍 | 实体书、电子书等 |

**公共字段**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| `id` | INTEGER | 自动 | 主键 |
| `title` | VARCHAR(200) | ✅ | 内容标题 |
| `title_alt` | VARCHAR(200) | ❌ | 副标题/别名（默认空） |
| `cover_url` | VARCHAR(500) | ❌ | 封面图 URL（默认空） |
| `description` | TEXT | ❌ | 内容描述（默认空） |
| `content_type` | VARCHAR(20) | ✅ | 内容类型（6 选 1） |
| `episodes` | INTEGER | ❌ | 集数/章节数（默认 0） |
| `status` | VARCHAR(20) | ❌ | 状态：airing/finished/upcoming（默认空） |
| `release_date` | VARCHAR(20) | ❌ | 发布日期（默认空） |
| `platform` | VARCHAR(50) | ❌ | 平台信息（默认空） |
| `source_type` | VARCHAR(20) | ❌ | 来源类型：bangumi/manual（默认 manual） |
| `source_id` | VARCHAR(50) | ❌ | 外部来源 ID（如 Bangumi ID） |
| `source_url` | VARCHAR(500) | ❌ | 外部来源链接 |
| `metadata` | TEXT (JSON) | ❌ | 各类型特有字段（默认 `{}`） |
| `is_public` | BOOLEAN | ❌ | 是否公开（默认 true） |
| `created_by` | INTEGER | ❌ | 创建者用户 ID |
| `created_at` | DATETIME | 自动 | 创建时间 |
| `updated_at` | DATETIME | 自动 | 更新时间 |

**各类型 metadata 示例**：

| 类型 | metadata 示例 |
|------|--------------|
| 番剧 | `{"episodes": 24, "air_status": "finished", "bangumi_rating": 8.5}` |
| 电影 | `{"director": "新海诚", "duration_minutes": 112}` |
| 游戏 | `{"developer": "miHoYo", "platforms": ["PC", "PS5"], "playtime_hours": 120}` |
| 软件 | `{"version": "1.0", "license": "MIT", "platforms": ["Windows", "Mac"]}` |
| 网站 | `{"url": "https://example.com", "category": "工具"}` |
| 书籍 | `{"author": "作者名", "isbn": "978-...", "pages": 300}` |

#### 3.1.2 内容 CRUD

**创建内容**：

| 要求 | 规格 |
|------|------|
| 触发 | 用户点击「添加内容」按钮 |
| 表单 | 根据 `content_type` 动态渲染不同表单字段 |
| 必填 | `title` + `content_type` |
| 可选 | 其他所有字段均可为空 |
| 导入方式 | 支持 Bangumi 搜索导入 + 手动填写 |
| 权限 | user / admin |

**编辑内容**：

| 要求 | 规格 |
|------|------|
| 触发 | 点击内容卡片 → 弹窗详情 → 点击编辑 |
| 表单 | 与创建相同，预填当前值 |
| 权限 | 创建者本人 或 admin |

**删除内容**：

| 要求 | 规格 |
|------|------|
| 触发 | 详情弹窗 → 点击删除 |
| 行为 | 确认弹窗 → 级联删除关联数据（评分、状态、标签） |
| 权限 | 创建者本人 或 admin |

#### 3.1.3 Bangumi 导入

| 要求 | 规格 |
|------|------|
| 搜索 | 调用 Bangumi API 搜索，显示结果列表 |
| 导入 | 一键导入：自动填充 title、cover_url、description、episodes、metadata |
| 标签 | 导入时自动抓取 Bangumi 标签 → `tag_type = 'bangumi'` |
| 去重 | 通过 `source_type = 'bangumi'` + `source_id` 去重 |
| 权限 | user / admin |

**Bangumi 导入流程**：
```
用户点击「从 Bangumi 导入」
→ 弹出搜索框 → 输入关键词 → 调用 Bangumi API
→ 显示搜索结果列表（标题 + 封面 + 年份）
→ 用户选择一项 → 预览确认
→ 自动填充表单 + 标签
→ 用户确认保存
```

#### 3.1.4 内容列表与筛选

| 参数 | 说明 | 示例 |
|------|------|------|
| `type` | 按内容类型筛选 | `?type=anime` |
| `status` | 按观看状态筛选 | `?status=watching` |
| `tag` | 按标签筛选 | `?tag=科幻` |
| `q` | 搜索关键词（标题 + 描述） | `?q=进击的巨人` |
| `sort` | 排序方式 | `?sort=rating` / `?sort=newest` |
| `page` | 页码（从 1 开始） | `?page=1` |
| `size` | 每页数量（默认 20） | `?size=20` |

**排序选项**：
- `newest`：最新添加（默认）
- `oldest`：最早添加
- `rating`：按均分降序
- `title`：按标题排序

#### 3.1.5 随机推荐

| 要求 | 规格 |
|------|------|
| 触发 | 首页「今天看什么」卡片 |
| 行为 | 随机返回一条 `is_public = 1` 的内容 |
| 权限 | 所有角色可见 |

#### 3.1.6 边界情况

| 场景 | 处理 |
|------|------|
| 标题超过 200 字符 | 前端截断显示 + 后端拒绝保存（422 错误） |
| cover_url 无效 | 显示默认占位图 |
| metadata JSON 格式错误 | 后端校验返回 422 错误 |
| 同名内容重复创建 | 允许（不强制去重，但 Bangumi 导入按 source_id 去重） |
| 删除有评分的内容 | 级联删除所有关联评分、状态、标签 |
| 内容类型不支持的筛选 | 忽略该参数，返回全部类型 |

### 3.2 评分系统模块

#### 3.2.1 数据模型

采用百分制（0-100）内部存储，UI 以 10 星半星显示。

**评分维度**：

| 维度 | 存储范围 | UI 显示 | 说明 |
|------|----------|---------|------|
| `score` | 0-100 | 0-10 星（半星步长） | 内容质量评分 |
| `recommend` | 0-100 | 0-10 星（半星步长） | 推荐度（如补番推荐度） |
| `review` | TEXT | 文字评论 | 可选评论 |

**特殊值**：
- `score = 0` 或 `recommend = 0`：表示「暂不打分」，不计入均分计算

#### 3.2.2 换算规则

| 输入 | 存储值 | 显示 |
|------|--------|------|
| 用户打 8.5 星 | 85 | 8.5 ★ |
| 用户打 10.0 星 | 100 | 10 ★ |
| 用户打 0 星 | 0 | 暂不打分 |
| 均分 85 | — | 8.5 分 |

**换算公式**：
- 星 → 存储：`存储值 = 星数 × 10`
- 存储 → 星：`星数 = 存储值 / 10`（四舍五入到 0.5）
- 存储 → 分数显示：`分数 = 存储值`（直接显示 0-100）
- 均分计算：`AVG(score) WHERE score > 0`，然后 `/ 10` 显示

#### 3.2.3 评分 UI

| 组件 | 规格 |
|------|------|
| 组件库 | shadcn/ui + 自定义评分组件 |
| 显示模式 | el-rate 风格，允许半星 (`allow-half`) |
| 步长 | 0.5 星（即 5 分） |
| 交互 | hover 预览 + 点击确认 |
| 三态 | 未评分态 / 查看态 / 编辑态 |

**评分三态**：

| 状态 | 显示 | 交互 |
|------|------|------|
| 未评分 | 「点击评分」提示 | 点击进入编辑态 |
| 查看态 | 星星 + 分数 + 评论 | 点击「修改」进入编辑态 |
| 编辑态 | 可交互星星 + 评论输入框 + 保存/取消 | 保存后回到查看态 |

#### 3.2.4 评分操作

**创建/更新评分**：

| 要求 | 规格 |
|------|------|
| API | `POST /api/v1/rating`（同一用户同一内容只保留一条） |
| 必填 | `content_id` + `score` |
| 可选 | `recommend`（默认 0）、`review`（默认空） |
| 权限 | user / admin |
| 唯一性 | `UNIQUE(content_id, user_id)`，重复提交覆盖 |

**删除评分**：

| 要求 | 规格 |
|------|------|
| API | `DELETE /api/v1/rating/:id` |
| 权限 | 评分创建者本人 或 admin |

#### 3.2.5 评分展示

**内容详情中的评分展示**：

| 元素 | 说明 |
|------|------|
| 均分 | score > 0 的评分平均值，显示为 `X.X 分` |
| 推荐均分 | recommend > 0 的推荐度平均值 |
| 评分人数 | score > 0 的评分总数 |
| 评分分布 | 各分数段的人数（可选） |
| 个人评分 | 当前用户对该内容的评分（如有） |

**最近动态**：

| 要求 | 规格 |
|------|------|
| 显示 | 最近评分的内容 + 评分者 + 分数 |
| 排序 | 按时间倒序 |
| 分页 | 默认 20 条/页 |
| 游客模式 | 匿名显示（无用户名，显示「匿名用户」） |

#### 3.2.6 边界情况

| 场景 | 处理 |
|------|------|
| score = 0 | 视为「暂不打分」，不计入均分 |
| recommend = 0 | 视为「暂不推荐度」，不计入推荐均分 |
| 重复评分 | 覆盖旧评分，更新 `updated_at` |
| 评分后删除内容 | 级联删除所有评分 |
| 全部评分为 0 | 均分显示为「暂无评分」 |
| 游客查看评分 | 只显示分数，不显示用户名/头像 |

### 3.3 观看状态管理模块

#### 3.3.1 数据模型

独立表 `user_content_status`，底层统一 4 个状态值，UI 按内容类型动态显示不同标签文字。

**底层状态枚举**：

| 状态值 | 说明 |
|--------|------|
| `want` | 想看/想玩/收藏 |
| `watching` | 在看/在玩 |
| `watched` | 已看/已玩 |
| `dropped` | 弃坑 |

**UI 标签按内容类型动态映射**：

| 内容类型 | want | watching | watched | dropped |
|----------|------|----------|---------|---------|
| 番剧 (`anime`) | 想看 | 在看 | 已看 | 弃坑 |
| 电影 (`movie`) | 想看 | 在看 | 已看 | 弃坑 |
| 游戏 (`game`) | 想玩 | 在玩 | 已玩 | 弃坑 |
| 软件 (`software`) | 收藏 | — | — | — |
| 网站 (`website`) | 收藏 | — | — | — |
| 书籍 (`book`) | 想读 | 在读 | 已读 | 弃读 |

**关键规则**：
- 软件/网站类型**只使用 `want` 一个值**，UI 显示为「收藏」
- 软件/网站不显示 watching/watched/dropped 选项
- 底层存储统一使用 `want/watching/watched/dropped` 四个值

#### 3.3.2 状态操作

**设置状态**：

| 要求 | 规格 |
|------|------|
| API | `POST /api/v1/status` |
| 请求体 | `{ content_id: number, status: string }` |
| 权限 | user / admin |
| 唯一性 | `UNIQUE(user_id, content_id)`，重复设置覆盖 |
| 软件/网站 | 只接受 `want` 值，其他值返回 422 |

**清除状态**：

| 要求 | 规格 |
|------|------|
| API | `DELETE /api/v1/status/:content_id` |
| 行为 | 删除该用户对该内容的状态记录 |
| 权限 | user / admin |

**获取状态列表**：

| 要求 | 规格 |
|------|------|
| API | `GET /api/v1/status` |
| 返回 | 当前用户的所有状态记录 |
| 用途 | 个人主页展示「想看/在看/已看完」列表 |

#### 3.3.3 状态 UI

**详情弹窗中的状态选择**：

| 内容类型 | 显示的状态选项 |
|----------|--------------|
| 番剧/电影/书籍 | 「想看」「在看」「已看」「弃坑」 |
| 游戏 | 「想玩」「在玩」「已玩」「弃坑」 |
| 软件/网站 | 「收藏」（仅一个按钮） |

**当前状态高亮**：
- 已设置状态时，对应标签高亮显示
- 点击已高亮标签 → 清除状态
- 点击其他标签 → 切换状态

#### 3.3.4 边界情况

| 场景 | 处理 |
|------|------|
| 软件/网站传入 `watching` | 返回 422 错误：「软件/网站类型仅支持收藏」 |
| 未设置状态 | 状态标签显示为未选中态 |
| 删除内容 | 级联删除所有用户状态记录 |
| 删除用户 | 级联删除该用户所有状态记录 |
| 游客操作 | 403 拒绝 |

### 3.4 标签系统模块

#### 3.4.1 数据模型

独立标签表 + 关联表，Bangumi 标签和自定义标签混合管理。

**tags 表**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | INTEGER | 主键 |
| `name` | VARCHAR(50) | 标签名（UNIQUE） |
| `tag_type` | VARCHAR(20) | `bangumi` 或 `custom` |
| `created_at` | DATETIME | 创建时间 |

**content_tags 关联表**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `content_id` | INTEGER | 内容 ID（级联删除） |
| `tag_id` | INTEGER | 标签 ID（级联删除） |
| PRIMARY KEY | — | `(content_id, tag_id)` |

#### 3.4.2 标签操作

**创建自定义标签**：

| 要求 | 规格 |

**手动添加标签**：

#### 3.4.4 标签展示

### 3.5 分享链接模块

#### 3.5.1 核心概念

分享链接 = 临时只读权限。不是单独的页面，而是后端的权限模式。

**核心规则**：
- 通过分享链接访问 = 获得临时游客会话
- 游客可浏览全站、搜索查询
- 游客**不可**执行任何写操作（评分、评论、状态标记等）
- 游客**不可**看到评分/评论者的用户名和头像

#### 3.5.2 数据模型

**share_links 表**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | INTEGER | 主键 |
| `token` | VARCHAR(32) | 随机 token（UNIQUE） |
| `created_by` | INTEGER | 创建者用户 ID |
| `expires_at` | DATETIME | 过期时间（NULL 表示永不过期） |
| `view_count` | INTEGER | 访问次数（默认 0） |
| `created_at` | DATETIME | 创建时间 |

#### 3.5.3 分享链接操作

**创建分享链接**：

| 要求 | 规格 |
|------|------|
| API | `POST /api/v1/content/:id/share` |
| 行为 | 为指定内容创建分享链接 |
| Token | 生成 32 位随机字符串 |
| 可选参数 | `expires_at`：过期时间 |
| 返回 | 分享链接 URL |
| 权限 | user / admin |

**说明**：分享链接目前支持分享单个内容，未来可扩展为分享整个站点。

#### 3.5.4 游客会话

**游客访问流程**：

```
用户访问 /guest/:token
→ 后端验证 token 有效性
→ 检查是否过期
→ 创建临时会话（JWT，短有效期）
→ 返回游客权限令牌
→ 前端以游客模式运行（只读 UI）
```

**游客 API**：

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/guest/:token` | 获取临时权限（返回 JWT） |
| GET | `/api/v1/guest/:token/content` | 浏览内容列表 |
| GET | `/api/v1/guest/:token/search` | 搜索内容 |

**游客视图差异**：

| 元素 | 登录用户视图 | 游客视图 |
|------|------------|---------|
| 评分 | 显示用户名 + 头像 | 显示「匿名用户」 |
| 评论 | 显示用户名 + 头像 | 显示「匿名用户」 |
| 最近动态 | 显示用户名 | 显示「匿名用户」 |
| 写操作按钮 | 显示 | 隐藏/禁用 |
| 分享按钮 | 显示 | 隐藏 |

#### 3.5.5 边界情况

| 场景 | 处理 |
|------|------|
| token 无效 | 返回 404「链接不存在或已失效」 |
| token 已过期 | 返回 410「链接已过期」 |
| 游客尝试写操作 | 返回 403「游客无权执行此操作」 |
| 链接被大量访问 | view_count 递增，不影响性能 |
| 创建者删除内容 | 分享链接仍可访问（显示「内容已删除」） |

#### 3.6.2 注册流程

```
→ 失败次数 +1
→ 失败 ≥ 5 次 → 锁定 15 分钟
→ 成功 → 重置失败次数 → 生成 JWT → 设置 httpOnly cookie

```

| 头像编号越界 | 使用默认头像（avatar_0.png） |

### 3.7 安全与防护模块

#### 3.7.1 限流策略

| 端点类型 | 限流规则 | 限流维度 |
|----------|---------|---------|
| `POST /auth/login` | 5 次 / 15 分钟 | 按 IP |
| `POST /auth/register` | 3 次 / 小时 | 按 IP |
| 其他写操作 (POST/PUT/DELETE) | 20 次 / 分钟 | 按用户 |
| 读操作 (GET) | 60 次 / 分钟 | 按 IP |

**限流实现**：
- 中间件层实现，基于 IP 或 JWT 中的 user_id
- 超出限制返回 `429 Too Many Requests`
- 响应头包含 `X-RateLimit-Remaining` 和 `X-RateLimit-Reset`

#### 3.7.2 登录安全

| 防护 | 规则 |
|------|------|
| 密码存储 | bcrypt 哈希（cost factor = 12） |
| 暴力破解防护 | 5 次失败锁定 15 分钟 |
| JWT | httpOnly cookie，有效期 7 天 |
| CSRF | SameSite cookie + JWT 校验 |

#### 3.7.3 输入安全

| 威胁 | 防护 |
|------|------|
| SQL 注入 | SQLAlchemy ORM 参数化查询 |
| XSS | React 天然转义 + CSP |
| CSRF | SameSite cookie |
| 恶意输入 | Pydantic 校验 + 长度限制 |

#### 3.7.4 数据安全

| 要求 | 规格 |
|------|------|
| 敏感配置 | 存储在 `.env` 文件，不入库 |
| 分享链接 Token | `secrets.token_urlsafe(24)` 生成 32 位随机字符串 |
| 密码重置 | v2.0 暂不支持（MVP 范围外） |

#### 3.7.5 边界情况

| 场景 | 处理 |
|------|------|
| 限流触发 | 返回 429 + 重试时间 |
| JWT 过期 | 返回 401，前端自动弹出登录框 |
| 用户被锁定 | 登录返回 429 + 剩余锁定时间 |
| 分享链接 token 碰撞 | 理论概率极低（2^192），碰撞时重新生成 |
| SQL 注入尝试 | ORM 层自动防御，无需额外处理 |

## 4. 用户流程

### 4.1 新用户注册流程

```
1. 用户访问 moreani.lovelysia.top
2. 未登录 → 自动弹出登录/注册弹窗
3. 用户切换到「注册」标签
4. 输入邀请码 + 用户名 + 密码
5. 点击「注册」
6. 后端验证
   - 邀请码无效 → 提示「邀请码无效」
   - 用户名已存在 → 提示「用户名已存在」
   - 验证通过 → 创建用户 → 自动登录
7. 跳转首页，弹窗关闭
```

### 4.2 内容添加流程

```
1. 用户点击「添加内容」按钮
2. 选择内容类型（番剧/电影/游戏/软件/网站/书籍）
3. 方式一：Bangumi 导入（仅番剧/电影）
   - 输入关键词搜索
   - 选择搜索结果
   - 自动填充表单 + 标签
4. 方式二：手动填写
   - 填写公共字段（标题必填）
   - 根据类型填写特有字段
   - 添加标签
5. 点击「保存」
6. 后端校验
   - 标题为空 → 提示「请输入标题」
   - 保存成功 → 关闭弹窗 → 刷新列表
```

### 4.3 评分流程

```
1. 用户点击内容卡片 → 打开详情弹窗
2. 查看内容信息 + 其他用户评分
3. 点击「评分」或已有的评分区域
4. 切换到编辑态
5. 点击星星设置 score（允许半星）
6. 点击星星设置 recommend（可选）
7. 输入评论（可选）
8. 点击「保存」
9. 后端校验
   - score 为 0 → 视为「暂不打分」
   - 保存成功 → 回到查看态 → 均分更新
```

### 4.4 观看状态流程

```
1. 用户点击内容卡片 → 打开详情弹窗
2. 查看当前状态（如未设置，显示所有选项）
3. 点击状态标签
   - 番剧/电影：「想看」/「在看」/「已看」/「弃坑」
   - 游戏：「想玩」/「在玩」/「已玩」/「弃坑」
   - 软件/网站：「收藏」
   - 书籍：「想读」/「在读」/「已读」/「弃读」
4. 后端保存/更新状态
5. UI 即时更新高亮
```

### 4.5 分享链接流程

```
1. 用户在内容详情弹窗点击「分享」
2. 后端生成分享链接
3. 用户复制链接
4. 发送给朋友
5. 朋友点击链接
6. 后端验证 token → 创建游客会话
7. 朋友以游客模式浏览内容（只读）
```

### 4.6 游客浏览流程

```
1. 通过分享链接访问
2. 自动进入游客模式
3. 可浏览全站内容列表
4. 可搜索内容
5. 可查看内容详情 + 评分 + 评论（匿名显示）
6. 尝试写操作 → 被拒绝（提示「游客无权操作」）
```
